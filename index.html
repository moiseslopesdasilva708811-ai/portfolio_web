TinyHub.AI

Pesquisa PIBITI · MIT

Plataforma livre que automatiza o pipeline de ML embarcado: ingestão de dados e EDA, pré-processamento, escolha do modelo, quantização INT8/INT4/FP32 e geração de header C++11 sem dependências para ESP32. Tem três modos de uso: Wizard guiado, Workflow no-code em canvas e Dashboard, com suporte experimental a SLMs.

  • TinyML
  • Quantização INT8/INT4
  • Flask
  • Tailwind CSS
  • C++ / ESP32
  • No-code

AquaMind IoT

IX Semana de C&T · UFRN

Sistema embarcado de baixo custo para telemetria e gestão automatizada de reservatórios de água. Usa ESP32 com sensor ultrassônico, bateria e painel solar, prevê o esvaziamento e classifica o risco em três níveis. API REST em Node.js e painel com histórico e alertas. Orientação do Prof. Thommas Kevin Sales Flores.

  • ESP32
  • Node.js
  • API REST
  • IA embarcada
  • Energia solar
